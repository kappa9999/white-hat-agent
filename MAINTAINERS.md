# Maintainers

White Hat Agent Core currently has one maintainer: [Amer (`@kappa9999`)](https://github.com/kappa9999).

The maintainer alone can:

- merge or revert pull requests;
- publish releases and packages;
- change repository rules, governance, or the trusted corpus;
- appoint or remove additional maintainers; and
- issue official security advisories.

Contributors receive credit in Git history and playbook metadata but do not become maintainers automatically. See
[GOVERNANCE.md](GOVERNANCE.md).
